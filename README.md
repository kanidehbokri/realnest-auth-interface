# Realnest Authentication Interface

A sleek and modern split-screen login page designed for a real estate platform. This project features a responsive layout built with semantic HTML5 and custom CSS styling, ensuring a smooth and elegant user authentication experience.

---

## Live Deployment
[Visit the Live Interface](https://kanidehbokri.github.io/realnest-auth-interface/)

---

## Technical Features
* Split-Screen Layout: Balanced design featuring high-quality imagery alongside a clean authentication form.
* Responsive Architecture: Fully optimized for mobile, tablet, and desktop viewing.
* Modern Form Elements: Custom-styled input fields and buttons for an enhanced user experience.
* Visual Storytelling: Strategic use of images to maintain brand consistency with the Realnest ecosystem.

---

## Core Technologies
* HTML5 - Semantic markup for forms and structure.
* CSS3 - Custom properties, Flexbox, and responsive media queries.
